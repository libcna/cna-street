# Asset attribution

**Every surface in this repository is generated. Sixteen models are not.**

That sentence used to read "nothing in this repository was downloaded", and the
change is the honest one: this project now imports third-party glTF models for
the props behind the shop glass, and the licence of each one is tracked
individually rather than assumed from the repository it came from.

Every surface, sign, glyph and mesh *of the street itself* is still generated by
code in this repository from a seed. There is no photographic texture, no
scanned material, no third-party font and no sound file, and the build's default
path needs no network.

## The imported models

`assets/external/manifest.json` is the record, and it is machine-readable so
that a validation step can check it rather than a person having to. Per asset it
carries the local name, the original title, the author, the copyright line, the
source URL and the repository it came from, the exact licence and its URL,
whether attribution is required, whether redistribution is allowed, the
retrieval date, the original format, the SHA-256 and byte count, what was done
to it, and what it is for in the scene.

**All sixteen are CC0-1.0 or CC-BY-4.0**, taken from
[KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets),
and the licence recorded for each is the one that repository states for *that
model* in its own `Models.md` — not the repository's overall terms. That
distinction is the whole point of doing this per asset: the same repository
carries models this project cannot use, and the manifest names them and says
why.

| Rejected | Licence | Why not |
| --- | --- | --- |
| Duck | SCEA Shared Source License 1.0 | Not compatible with this repository's MIT terms |
| Sponza | CRYENGINE Limited Licence Agreement | Redistribution restricted |
| Virtual City | 3DRT, testing use only | Not licensed for use in a published work |

The models are **fetched, not committed**. The set is about 110 MB of 4K-textured
product-shot assets, and putting somebody else's work into a repository's
permanent history is a separate permission from using it. `scripts/fetch-assets.sh`
reads the manifest, fetches each file and verifies its digest before it is used;
a checkout that has not run it simply has no imported props, and every one of
them has a procedural fallback.

## Why everything else is generated

That is a deliberate architectural choice rather than a way of avoiding the
question. A generated surface can be produced at any resolution, tiles by
construction, carries a physically sensible roughness map instead of a guessed
one, and — because it comes from a seed — is byte-identical on every machine
that builds the repository. The cost is that each one has to be *authored*:
`street/src/Assets/TextureFactory.cpp` is a description of what asphalt, brick,
lime render, clay pantile, tree bark and car paint actually look like, not a
call into a noise library.

## Where each kind of asset comes from

| Asset | Generated by | Notes |
| --- | --- | --- |
| Surface textures (albedo, normal, ORM) | `Assets::TextureFactory` | Tileable by construction; every map is derived from the same height field so they agree. |
| Traffic sign faces | `Assets::SignFactory` | **Original artwork.** See the note below. |
| Street-name plates, shop fascias, number plates | `Assets::SignFactory` | Lettering drawn with the stroke font below. |
| Lettering | `Assets::Canvas`'s stroke font | A signed-distance stroke font written for this project: digits, upper and lower case, and the punctuation the signage needs. |
| Overlay font atlas | the same stroke font | Baked to a 512 px atlas at start-up. |
| Buildings, road, furniture, vehicles, people, trees | `street/src/Props/*` | Meshes built from the dimensions in `Scene/StreetMetrics.hpp`. |
| Sky and clouds | `CNA::Graphics::AtmosphericSky` plus this project's cloud shader | Analytic; no sky photograph or HDRI. |
| Environment lighting | `CNA::Graphics::EnvironmentProcessor` | Irradiance, prefiltered specular and BRDF LUT baked at start-up from the same analytic sky. |

## A note on the traffic signs

The sign faces are **original designs in the visual language of continental
European signage**. The shape-and-colour grammar they follow — a red-ringed
white disc prohibits, a red-bordered white triangle warns, a blue rectangle
informs — is a functional convention rather than anyone's artwork, and it is
what makes a sign readable at a glance. The pictograms inside them are drawn in
`SignFactory` rather than traced from any jurisdiction's official artwork, which
would bring that jurisdiction's licence with it. Nothing here reproduces a
specific real sign, a specific real street, or any real organisation's marks.

The street names, shop names and vehicle registration on the plates are
invented.

## If an external asset is ever added

It would go in this table with its name, source URL, author, licence,
modifications and the date it was obtained, and its licence would have to be
CC0, public domain, or a permissive licence that allows redistribution in this
repository. CC-BY would need the attribution reproduced here. Assets with
unknown licences, and assets extracted from commercial games, are not
acceptable at any quality.
